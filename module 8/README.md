This project is a small Python command‑line tool that scans files or directories for hardcoded secrets using simple regex patterns. It looks for things like API keys, passwords, tokens, AWS access keys, and private key blocks, then reports where they appear in the code along with the line number. The tool uses only built‑in Python modules, so anyone with Python 3 can run it without installing anything extra. To use it, you just run the script and give it a path to scan, and if no path is provided it scans itself by default. Logging is included so you can see what the scanner is doing while it runs. This tool is meant to help catch sensitive information before it ends up in commits or shared code.
