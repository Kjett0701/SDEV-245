This project is a simple Python secret‑scanning tool that checks any file or folder for sensitive information such as API keys, passwords, tokens, AWS keys, and private keys. It works by reading each file line‑by‑line and matching the content against a set of regular‑expression patterns. When it finds something, it reports the filename, line number, type of secret, and the exact matched text. You can run the script by giving it a file or directory path, and if no path is provided, it automatically scans itself.
